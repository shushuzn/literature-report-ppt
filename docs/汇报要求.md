# 汇报要求（原文存档）

> 来源：2026-10-15 的作业通知，原文存档。
> 定位：**输入样例，不是框架的验收标准**。框架判什么、判到多少，由各项目
> `content.yaml` 的 `compliance` 段决定。换一次汇报就换一份这样的要求，
> 代码和文档都不用改。下文 P1–P5 亦只是这一次的页序，`deck` 列表可增可减。

---

## 一、汇报选用文献要求

| # | 要求 | 阈值 |
|---|---|---|
| A1 | 发表时间 | 近三年内 |
| A2 | 文献类型 | SCI 研究性论文 |
| A3 | 中科院分区 | 二区及以上 |
| A4 | 影响因子 | > 8 |
| A5 | 综述类 | 严禁选用 |

## 二、PPT 格式要求

| # | 要求 | 阈值 |
|---|---|---|
| B1 | 图文并茂 | 需配图 |
| B2 | 页码 | ≤ 5 页 |
| B3 | 汇报时间 | ≤ 3 分钟 |
| B4 | 中文字体 | 微软雅黑 |
| B5 | 英文字体 | Times New Roman |
| B6 | 字体大小 | ≥ 20 pt |

## 三、PPT 内容要求

| 页 | 内容 |
|---|---|
| 第一页 | 汇报主题，姓名，导学团队指导老师信息等 |
| 第二页 | 汇报文献题目，发表期刊，分区，影响因子，作者信息，发表时间（可直接截图论文首页） |
| 第三页 | 材料制备机理，每个组分加进去的作用？ |
| 第四页 | 材料主要性能有哪些？为什么会有这些性能？ |
| 第五页 | 主要应用是什么？ |

## 四、汇报口头要求

- **切记汇报时不要大段大段读文字，只需讲出来重点即可。**
