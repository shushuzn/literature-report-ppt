# 文风规范：标题说清这页讲什么，句子说人话

版式管「放得下」，这一份管「读着真」。两条要求：

1. **标题先说清这页在讲哪一块。** 文献汇报用任务名（照汇报要求原话），
   讲自己的研究才写判断。两类都不带逗号、冒号、分号。
2. **不用 AI 腔句式。** 对偶转折、空转过渡词、口号收尾、抒情破折号。

`tools/style_check.py` 把第 2 条和标点做成了可执行的规则表，已并入 `verify.py` 第 1 步。

---

## 一、标题用哪套写法，看这页在讲谁的工作

**文献汇报：标题就是任务名。** 你复述的是别人已经发出来的结论，页面标题的作用
是让听众知道你正在讲哪一块，不是让你宣布一个判断。照当次要求里每一页的原话写
（`docs/汇报要求.md` 第三节是其中一例，换了要求就照新的那份）：

| 页 | 标题 |
|---|---|
| 封面 | 论文题目中译 |
| 信息页 | 论文基本信息 |
| 制备页 | 材料制备与各组分作用 |
| 性能页 | 主要性能与成因 |
| 应用页 | 主要应用 |

页数不由这里规定：`deck` 写几页就是几页，标题跟着当次要求的分法走。

理由有三条。第一，听众走神回来，抬头`论文基本信息`立刻知道进度；
写成`该文 2026 年发表于 Nature Communications`，他得读完整句才知道这页在交材料。
第二，判断是作者的，不是你的；把作者结论放到标题最显眼的位置，等于替他站台，
老师第一个问的就是「你自己怎么看」。第三，第二页下面七行字段已经把期刊、
分区、影响因子写全了，标题再复述一遍是纯冗余。

封面同理：用论文题目的中译（`碳纳米孔中的连续部分去溶剂化`），
不要另造一句`部分去溶剂化把双电层容量翻了一倍`——那是你的总结，
不是这篇文献的题目，两处对不上，翻页时听众会以为讲了两篇。

**综述提纲：用提纲名，不写判断。** 综述讲的是别人做的十几年工作，标题的
作用是给听众一个目录——`理论认识与材料制备的发展脉络`、`多孔碳制备的四个阶段
与相应代价`、`现存瓶颈与后续方向`。这些是名词短语，但不空：每一个都交代了
这一页的范围。作者的判断（`瓶颈在概念层面`）留到讲的时候说，或者写进卡片，
不要摆在标题上替他站台。

**讲自己的工作：标题写判断。** 这时页面标题才是你的主张：

| 标签（改前） | 判断（改后） |
|---|---|
| 五类孔构型：各自解决什么、付出什么 | 五类孔构型各有各的代价 |
| 从试错到预测：表征与机器学习 | 模型与原位表征让性能可以先算再测 |
| 对后续工作的启示 | 四项后续工作能从这份综述直接接出来 |

判断标准只有一条：**标题那句话必须被这一页的证据兜住**。兜不住就是虚张声势，
比写标签更糟。也别拿标题去连读成故事——那是给「只看标题不看正文」的阅读型
deck 用的做法。学术汇报里听众在听你讲，标题只服务于抬头的那一秒。

### 两档标题模式，写在 content.yaml 里

上面三套写法由 `title_mode` 选，检查器据此决定查哪一套：

| `title_mode` | 用于 | 检查器要求 |
|---|---|---|
| `label` | 文献汇报、综述提纲 | 标题写成名词短语（任务名）；查标点、口语，并**反过来查有没有偷偷写成判断句** |
| `thesis`（默认） | 讲自己的工作 | 标题必须含谓词或数值，只有名词会报「名词短语标题」 |

不写就是 `thesis`。文献汇报与综述这几类稿子写成判断句，会同时犯两个错：
替作者下结论，以及为了凑谓词把标题写成说书腔。

**`label` 也要查判断句，而且是严重。** 这一条是补上去的：早先只查标点与口语，
于是 `现有瓶颈集中在概念层面`、`下一步从孔径优化转向传输与电子结构` 两条判断句
混在 `论文基本信息`、`多孔碳制备的四个阶段与相应代价` 之间，一路通过。
单看每条都通顺，翻页时才觉出语体在变——**语体不一致是横向问题，规则得横向比对
才看得见**。现在 `label` 模式用一张谓词表（`集中在`／`转向`／`下一步`／`难以`／
`尚未`／`提高`／`实现`…）判，命中即严重，改法二选一：改成名词短语
（`现有瓶颈集中在概念层面` → `概念层面的四个瓶颈`），或整篇换 `title_mode: thesis`。

卡片名、阶段名同表只报**提示**不报严重：小标题写短句读得通，不像页标题那样扎眼，
但一页四条全是判断句、下一页全是名词，同样会断，值得自己回头看一眼。

### 标题不用口语和比喻

标题是投影出去的门面，正文字和讲稿可以说人话，标题不行。检查器对页标题与
卡片名跑一张口语词表（`TITLE_COLLOQUIAL`），命中判严重：

| 别写 | 写成 |
|---|---|
| 造孔的四级台阶 每级都要还上一级的账 | 多孔碳制备的四个阶段与相应代价 |
| 好看的数字出自宽松测法 | 测试条件宽松使数据偏高 |
| 比表面积管不住性能 | 比表面积与电容缺乏相关性 |
| 孔细到装不下溶剂壳 | 亚纳米孔内的部分去溶剂化 |
| 二氧化硅做模具，孔径第一次可定 | 以二氧化硅为模板，孔径首次可控 |

判据是「这句话能不能出现在答辩 PPT 的目录页上」。口语化不是错，放错位置才是：
把这些话放讲稿里，讲的时候说出来比写在屏幕上自然。

### 标题里不出现逗号和冒号

这是最容易漏、也最像 AI 的一条。判断句不等于「两个短句用逗号焊在一起」：

```
同一块碳，电容从 85 涨到 172 F/g        ← 前半句铺垫，后半句结论
换电解液，让溶剂化离子带着壳进孔          ← 条件 + 结果
软包 40 Wh/kg，循环三万次                ← 两个并列事实
Nat. Commun.：醚类电解液打开了双电层容量  ← 冒号等于「主题 + 展开」
```

读的人要在半句处换一次焦点，一页换一次，十页就是十次。改成一句主谓宾：

```
同一块碳的比电容从 85 涨到 172 F/g
醚类电解液让溶剂化离子带着壳进孔
软包电芯循环三万次容量保持七成
这是一篇一区 TOP 期刊的研究论文
```

依据是两处独立来源，不是我的偏好：

- **High Bridge Academy** 的五条 action title 规则，第 1 条写明
  "Write one complete sentence. No fragments, no colons, no 'Key Findings:'"
- **StrategyU** 引 Minto《金字塔原理》："Use statements not captions"，
  并把「用 and 连接两个独立主张」直接判为「这是两页，不是一页」

中文里对应的那个「and」就是逗号。真有两个判断，拆页，别折叠。

配套的还有两条：**小标题（卡片名 / 要点名）同受约束**，`涨的是双电层，
不是副反应` 这种和标题一样要改；**顿号只提示**，`孔径、连通性、掺杂构型`
这类名词并列在读标题时还能接受，但谓词落地太晚，能改就改。

## 二、AI 腔清单

这些句式的共同点是**把话说得比事实漂亮**：单句都通顺，连读十句就露馅。
判断依据是密度而非绝对次数——一篇文章出现一次是修辞，一段出现三次是模板。

### 严重：交稿前必须改

| 句式 | 例子 | 为什么不行 | 改法 |
|---|---|---|---|
| 不是…而是 | 这不是二选一，而是要在同一个结构里同时满足 | 把可以并存的两件事写成二选一 | 直接说后半句 |
| 不在…在… | 瓶颈在概念，不在材料 | 同上一族，只换了连接词 | 说清瓶颈具体卡在哪一步 |
| 而非 | 分级孔多是统计分布，而非受控网络 | 书面腔，且暗含对立 | 直陈，另起一句再说差别 |
| 不仅…而且 / 与其…不如 | 不仅提了电容，更是改了界面 | 递进壳子，删掉不减信息 | 两件事分开说 |
| 值得注意的是 / 总的来说 / 事实上 | 值得注意的是，数据仍偏少 | 空转，删掉不影响语义 | 从事实起句 |
| 一句话 / 归结起来 | 一句话：从堆面积转向设计连通性 | 把结论压成标语，落不了地 | 写成具体动作或判断 |
| 破折号插入解释 | 功率高、能量低——这道取舍写在结构里 | 中文正文里破折号一多就像翻译稿 | 改冒号或句号 |

### 提示：看语境决定

| 句式 | 说明 |
|---|---|
| 正反问（是不是 / 能不能 / 在不在） | 书面汇报里显得随意；确需设问用「是否」 |
| 从…到… | 两端不在同一维度时是凑范围；同维度的真实区间（`1 到 10 mg/cm²`）放行 |
| 极大地 / 显著地 / 有效地 | 换成具体幅度：涨了多少、差几倍 |
| 进行了…研究 / 起到…作用 | 名词化空壳，换成实义动词 |
| 三段排比、等长并列 | 三项一组、每条等长，是最明显的机器节奏。允许一次，别当口头禅 |

### 不算问题的

- **对照页的平行结构**（`compare` 的左右两栏）：平行是阅读需要，不是文风毛病。
- **术语重复**：`赝电容` 反复出现很正常，学术文本里同一概念就该用同一个词，
  不要为避重复而换同义词。
- **`显著`**：有统计含义时保留。

## 三、节奏

规则表管不住节奏。真实写作句子长短不齐，AI 写出来是等长的柏油路。
三条自查：

- **每页至少有一句短句。** 全是 25 字以上的长句，读起来没有落点。
- **卡片之间不要等长。** 三条卡片的正文都是一行、都 30 字，一眼就是模板。
  让一条一行、一条两行，或者一条展开、一条压成短语。
- **不要每段都带小标题。** `cards_grid` 的 name + desc 结构已经足够，
  再在 desc 里写「首先、其次」就重复了。

## 三之二、综述页别把数字排成清单

综述讲的是**别人的结论**，听众要的是关系与走向：哪条路线更好、每一步
换来什么又赔了什么。一张卡里同时摆 `300–500 F/g`、`10 mg/cm²`、`100 μm`、
`50–80%` 四个数，听众既记不住也来不及比，反而不如一句「保持率往往掉一半
以上」。

研究论文正好相反：讲的是自己做了什么，**数据就是内容**，一页六张卡六个数
是正常的。所以这条规则只对综述项目生效，且要在 content.yaml 里显式打开：

```yaml
review:                            # 有这一段 = 综述项目
  min_nodes: 10
data_density: true                 # 默认关闭，开了才查
```

打开后查两件事，都只报提示：

- **单卡数据堆砌**：一张卡的正文（desc/cost）里超过 3 个数。
- **同页语体不齐**：同一页各卡的数字个数落差 ≥ 3——三张零数据、一张四个数，
  翻过去能感到语体变了，混在判断之间的数据播报最扎眼。

改法不是删数字，是**换成比较式表述**：数字细节放讲稿里讲，版面留给关系。
「保持率往往掉一半以上」比一串负载、厚度、掉幅好懂；「比表面积最高」
比「2000 m²/g」更适合做一张卡片的落点。

**别为了减数字把文风改口语。** 减掉的是数值，不是书面语。「电容保持率
往往掉一半以上」是汇报，「能保住的比例往往不到一半」不是——同样是比较，
后者把书面语一并降级了。

## 四、怎么用工具

```bash
# 单篇检查
python tools/style_check.py projects/<项目>/content.yaml

# 全部项目（含文风）
python tools/verify.py --all

# 提示项也算不通过（严格模式）
python tools/style_check.py projects/<项目>/content.yaml --strict
```

输出定位到字段路径与命中的句子，改完重跑。除了句式，还会报四项：

- **标题带逗号/冒号**（严重）：`deck[i].title` 出现 `，：；`。封面与章节页也查。
- **小标题带逗号**（严重）：`cards[i].name` / `items[i].name` 同样只留一个判断。
  冒号放行——`EC:DMC 电解液` 是化学写法。
- **用词密度**：「关键」平均每 400 字出现一次以上、「决定」每 500 字一次以上，
  说明在靠同一个词撑逻辑关系。
- **名词短语标题**（thesis 模式）：标题里没有动词或数字，多半是标签。
- **标签模式写判断句**（label 模式，严重）：标题里出现谓词，与全篇栏目名不是一种语体。
- **小标题写成判断句**（label 模式，提示）：卡片名与阶段名同一条线，只提示。

`projects/_` 开头的目录是示例与骨架，文案本身是占位说明，
只报告不阻断（`run_one` 里的 `demo` 分支）。

## 五、这套规则的边界

**规则表能抓句式，抓不到空洞。** 一句「掺杂提电容的代价是抬高电阻」合规，
但它成立是因为背后有 30–50% 的实测数字；换个题目，这句话就是空话。
所以文风检查只是第一道，后面还有：

- 事实必须能指回原文（图注标 Fig. 编号，数值不改写）
- 讲稿 `notes` 要能口述（`export_notes.py` 按 220 字/分钟估时）
- 版面九维度（`audit_all.py`）

三道都过了，稿子才既装得下、又读得通、又说得出口。

## 规则来源

句式清单参考了几份公开的去 AI 味实践与顾问公司的标题写法，按中文学术汇报
的语体做了删改：

- action title：讲自己的研究时，标题说结论不说标签，且结论要能被本页证据兜住
  （文献汇报不适用，见第一节）
  - High Bridge Academy《Action Titles》五条规则，第 1 条：一个完整句子，
    no fragments, no colons；第 5 条：两行以内，超了就是两页
  - Minto《The Pyramid Principle》："Use statements not captions"
- **未采用**：顾问做法里「只读标题就能复原整个论证」的 ghost deck 检验。
  它假设读者不读正文、只听汇报；而听众是在听讲述，标题只需照顾抬头那一瞬。
  把标题当故事读，会把每页的结论削成同一节奏的对偶句——正是这套规则要治的病。
- AI 写作的语言指纹：对偶转折、三段排比、虚假范围、破折号、空转过渡词
- 中文学术润色：术语一致性优先于同义替换；正文不用粗体和破折号做强调

未采用的部分：要求「加入口语、犹豫、个人偏好」以制造人味——汇报稿的语体
不允许，这一条只适用于随笔。
